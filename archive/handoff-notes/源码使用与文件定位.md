# 素材与源码使用

## 最方便的编辑方法

直接修改 `01_当前汇报` 的主稿；三张新主图分别在 `02_三张主图`，都是可编辑对象。所有当页素材已嵌入 PPT，不依赖原作者电脑。`workspace` 仅供重绘、查证和后续代码修改，不需要先运行它才能改 PPT。

## 相对路径工程

打开 `workspace` 作为工作目录，代码里的 `work/...` 和 `outputs/...` 才有正确的相对关系。

| 内容 | workspace 内路径 |
|---|---|
| 当前配色与三张主图 | `work/palette_refresh_20261016/` |
| 原理图 / 总流程 / 训练图代码 | `principle.mjs` / `workflow.mjs` / `training.mjs`，均在上述目录 |
| 原生形状绘图工具与颜色 | `styled_art.mjs`、`figure_style.mjs`、`palette.json` |
| 整合到完整 PPT 的脚本 | `work/palette_refresh_20261016/assemble.py` |
| 整合前的 14 页基底 | `outputs/TerraScope_版式重构版_20261016/TerraScope_课堂汇报_14页_版式重构.pptx`，仅构建依赖 |
| 最新逐页文字 | `work/palette_refresh_20261016/talk.json` |
| 原整页版式及图表布局 | `work/editorial_v2_20261016/redesign.mjs`、`build.mjs` |
| 当前案例原图、GT、预测与差异图 | `work/final_talk_20261016/assets/` |
| 局部放大、训练样本和四视图素材 | `work/editorial_v2_20261016/assets/` |
| 实际指标与案例元数据 | 上述目录中的 `data.json`、`measurements.json` |
| 7571 原理图素材 | `outputs/TerraScope_洪灾对齐修正版_20261015/逐景证据/evaluation/7571/` |

PNG 命名：`ID_rgb` 原图；`ID_mask_gt` 二值真实标签；`ID_gt` 标注叠加；`ID_baseline` 原模型叠加；`ID_single_view` 优化单视图；`ID_tta4` 四视图叠加；后缀 `_mask` 表示纯二值掩膜；`_difference` 表示空间误差。不要把叠加图再当成二值掩膜处理。

## 重建三张主图

这些脚本使用 Node.js 的 `@oai/artifact-tool`，由 Codex 工作区依赖提供。请调用当地 Codex 的依赖加载工具确定运行时；不要直接使用原作者 Mac 的绝对路径。若当前环境没有该库，直接编辑原生 PPT 即可。

在 `workspace` 目录执行 `principle.mjs`、`workflow.mjs`、`training.mjs`，会在 `work/palette_refresh_20261016/figures/` 下生成三张候选 PPT 和预览。随后使用带 `lxml` 的 Python 执行 `assemble.py`，产生完整候选 PPT。最终需按当地的演示文稿工具流程验证，并保存新版本。

`prepare.py` 是上次生成配色脚本的历史步骤，会覆写主图脚本；不要在已手工修改脚本后随意重跑。`finalize.mjs`、`render_final.mjs` 的依赖路径是原 Mac 环境，需要在新电脑改成当地工具路径。源码是可接续的工程快照，并非已在所有 Windows 环境一键验证的安装包。

原版整页构建链会引用用户的模板、旧候选文件和其他历史路径。当前提供的完整基底和 `assemble.py` 足够重建三张图的整合版，无须先重跑整个历史链。素材图全部已提供，字体需要使用系统中合法安装的字体；宋体替换后检查行高和换行。

## 图像对齐

同一案例的 RGB、标签、预测必须共享网格。掩膜只能使用最近邻等保持类别的方式变换；局部放大必须使用同一 `(left, top, right, bottom)`；不要给三张图分别做“填满裁剪”。四视图预测必须先逆翻转再平均。

7301 局部窗口为 `(60,100,655,590)`；7461 为 `(100,90,770,600)`；7986 为 `(110,180,800,690)`，对应 `extra_assets.py`。现在提供的成品局部图已经按共同窗口裁好。

## 包内实验证据及省略范围

包含原模型、微调、LoRA、模块、夜间训练、参数平均、四视图及空间提示的结果 JSON、协议、样本清单和预测掩膜；保留训练/推理代码用于说明方法。展示使用的 10 个样例有 RGB 和语义标签；其他样本保存了样本清单、统计与预测，未重复打入全量 RGB。

不包含完整模型权重或全部数据集，不是可离线从零训练的环境包；也没有打包账号凭据、充值/运行控制截图、自动开关机控制器、虚拟环境或 node_modules。复述/优化 PPT、重画主图、核对统计不需要这些内容。

模型源码快照位于 `work/terrascope_preflight` 及 `work/terrascope-src/TerraScope/third_parts/sam2/modeling`；仅供核对结构，不能当成完整权重分发。

`文件来源索引.json` 记录拷入文件的原始位置；路径是历史来源，不是声称接手电脑上存在那些绝对目录。压缩包完整性可用根目录 `verify_package.py` 检查。
