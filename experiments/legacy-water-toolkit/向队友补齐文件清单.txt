发给队友的技术资料清单

我会先基于官方 TerraScope 做“投影层 + SAM2 解码器”小预算微调。当前分享包有结果
表格、指标和展示材料，但没有找到训练/推理源代码、模型权重、原始输入 GeoTIFF。
为复现你现有结果并避免用到测试集训练，请提供下列文件；PPT、讲稿与展示配图不用补。

A. 复现你当前结果必须要有

1. 完整代码仓库压缩包或 Git 链接 + commit。
   包含实际执行的推理脚本、数据读取、RGB 生成、提示词模板、掩码提取、resize、
   nodata 处理、面积计算、指标统计、道路裁剪/配准、筛选与汇总脚本。
   包含 CLI 启动命令、配置文件、requirements / pip freeze、运行日志。
   不只提供 notebook 截图；若用 notebook，请附 .ipynb 与依赖和执行顺序。

2. 模型的准确来源与版本。
   如果没有额外训练：HF repo ID + revision + checkpoint 文件名即可，官方权重可重下。
   如果用过自训练/LoRA：提供 adapter/full checkpoint、对应底模、训练配置与转换命令。
   HF 格式应包含全部 model-*.safetensors、index.json、config、tokenizer、自定义 .py。
   如果只有 .pth / DeepSpeed 分片，说明保存方式并附所有分片，不能只给一个索引文件。

3. Sen1Floods11 原始输入、标签和精确样本清单。
   每个 sample_id 对应 S2Hand.tif、LabelHand.tif、当时输入模型的 RGB 原图。
   官方原始数据可自动下载；但必须补你当时生成 RGB 的脚本/参数，以区别模型变化和
   图像拉伸变化。明确波段顺序、反射率缩放、百分位拉伸、输入大小、裁剪与重采样方式。
   提供 train/val/test IDs，说明是否曾在分享包测试样本上调提示词、阈值或参数。
   目前审查到的 72 个水体样本都在官方 test，不能拿来微调或当独立验证集。

4. 逐样本原始预测，而非只有表格或彩色叠加图。
   最好提供浮点 logits/probability（.npy/.npz/.tif），至少提供原始二值 mask。
   提供 mask 的尺寸/数值含义、预测阈值、原图坐标关系；标注是否有多候选、多次提示。
   每个问题的完整原始文本输出、[SEG] 对应第几个掩码、解析后数值与单位也需保留。
   这样才能定位“答案对但掩码算错”、面积单位、SEG 对应关系、resize 等问题。

5. 结果行到原始文件的一一映射。
   至少包括 100 QA、12 full-valid、65 正水体、200 筛选、71 复核候选的 sample_id，
   RGB、标签、预测路径、问题/提示词、正确答案与评分方式。相同 ID 多问时保留 question_id。
   不需要把当前包中已有 CSV 再发一遍；补齐 CSV 到输入/预测文件的关联表即可。

B. 要复现道路洪灾部分还必须补

6. FloodNet 原始图像、语义标签、split 清单、类别编码；原始道路预测/评估脚本。
   48 个道路样本的准确路径、GT 像素定义，以及“受淹道路”和“可见积水”的口径。
7. 那 31/56 配准修正的脚本、修正前后坐标/变换、最终样本清单和原始日志。
   附道路范围的来源：如果现在是 GT 道路范围，请明确说明。
   要声称端到端道路核验，需要独立道路矢量或独立道路检测结果，不能把 GT 当模型输入。
8. 若要计算“新增洪水”而非“所有水体”，补灾前/灾后时间、配准影像和独立水体变化标签。
   仅用 JRC 排除常年水还不能替代灾前灾后变化真值。

C. 可以直接从官方获取，不必等你重新打包

9. 官方 TerraScope 完整模型（若使用的是未改动的官方版本）。
10. Sen1Floods11 v1.1 全部 446 张手工标注样本的 S2Hand/LabelHand 与官方四组划分。
    微调需要 train 252、val 89；最终评估 test 90、Bolivia 15。
11. 官方 SAM2 实现在 HF 模型中已经提供；本实验不要求另找一个来源不明的 sam2.pt。

最低开跑条件与等待边界

只做“新官方基线 + 新微调”：可以用 C 的官方下载先跑，前提是模型、数据完整且真实 GPU
预检通过。还缺 A 时，必须把结果标成新的 R1/M1/M2，不能写成已复现并提升了队友旧模型。

要准确解释队友效果不好的原因、计算相对旧方案 R0 的提升：A 的 1–5 项都需要补齐。
要沿用道路洪灾结论：再补 B；这些不阻塞本轮水体实验。
