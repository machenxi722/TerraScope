# TerraScope 水体微调工具包

目标：在总预算 **200 元、单卡租期不超过 24 小时** 内，验证“冻结 TerraScope 主体，只微调文本到 SAM2 的投影层与掩码解码器”是否改善水体分割和面积估计。先做 Sen1Floods11 水体实验；道路与植被需要另外的数据与协议。

这是可执行的实验工具包，**不是已经训练完成的模型**。本地 CPU 单元与流程测试见 `VALIDATION.txt`；完整 TerraScope 8B、真实遥感数据和 CUDA 的端到端训练仍待服务器预检。没有代租服务器，没有发生 GPU 训练费用。

## 官方代码基线

- [TerraScope 官方仓库](https://github.com/shuyansy/Earth-Observation-VLMs/tree/12b9970fca8d87ea3978c55a8f8fceddfd8efc2e/TerraScope)：`12b9970fca8d87ea3978c55a8f8fceddfd8efc2e`。
- [官方 HF 模型 sy1998/TerraScope](https://huggingface.co/sy1998/TerraScope/tree/a2333262586f8a07238d85db85061979198435fc)：`a2333262586f8a07238d85db85061979198435fc`。
- 实际使用官方模型随附的 `sam2.py` 内 `PromptEncoder`、`TwoWayTransformer`、`MaskDecoder`，以及官方 HF 模型的图像预处理、图像嵌入和 Qwen2 主干。没有用一个形状相似的自建解码器替代 SAM2。
- 不启动官方大规模 XTuner/DeepSpeed 混合数据集训练器。本工具包在官方最终 HF 模型上构建轻量训练入口，因此不要求 MMCV、MMDet、DeepSpeed 或 FlashAttention 编译。
- `vendor_metadata` 保留上游文件及版权声明，不改变上游授权；模型及数据的使用继续适用各自原始条款。

## 训练定义与比较对象

| 名称 | 改变什么 | 用途 |
|---|---|---|
| R0 | 队友原来的代码、图片、提示词、自由生成流程 | 旧结果复现；需要队友补齐文件，本工具包不冒充其复现 |
| R1 | 官方冻结权重 + 本工具包固定提示词 / 固定助手前缀 | 所有微调比较的直接基线 |
| M1 | 从 R1 初始化，训练投影层与活动的掩码解码分支 | 检验低成本监督适配 |
| M2 | 从同一个 R1 独立初始化，在 M1 损失上加面积一致性 | 检验面积监督是否有额外价值 |
| 第二种子 | 只按验证集选择 M1 或 M2 配置，换种子从 R1 重新训练 | 看提升是否受单次随机性影响 |

R1 不是原始自由生成的 TerraScope：用户提示词固定为 `Segment all visible surface water in this satellite image.`，助手前缀固定为 `Water [SEG]`。使用该唯一 `[SEG]` 的**输入经过语言主干后**的隐藏向量。前缀对每张图一致，不使用真实答案、比例、点、框或掩码，也不从标签裁图。

这是一条固定任务的分割通路：即使图中无水，也执行同一通路并允许预测空掩码。它不等价于训练自由问答能力。`M1−R1`、`M2−R1` 才是微调收益；`R1−R0` 包含提示词、图像处理、生成策略等流程差异。需要用 R0 原始输入重跑后才能拆分这些影响。

SAM2 一次产生三个候选掩码，**推理始终根据预测 IoU 选一个**，与官方首帧多候选路径一致。训练同时监督三个候选，避免只对 argmax 分支传梯度；IoU 质量分支使用停止梯度的真实 IoU 作为回归目标。没有用真实 IoU 选测试掩码。

冻结：Qwen2、InternVL 图像编码器、视觉到语言的 `mlp1`、SAM2 图像编码器与提示编码器、记忆模块。训练：`text_hidden_fcs` 对应的投影 MLP，SAM2 解码器及其 `conv_s0` / `conv_s1`、候选掩码分支、IoU 分支。当前单图三候选路径不使用的目标存在性输出 MLP、单候选编号 0 的输出 MLP 显式冻结；不声称这些分支也获得了有效微调。

## 缓存为什么不会截断梯度

缓存两个冻结模块的输出：

1. **投影层之前**的 `[SEG]` 隐藏向量；不缓存已经映射到 256 维的语言提示。
2. **解码器两个高分辨率投影卷积之前**的 SAM2 原始 FPN；直接调用 `image_encoder()`，不调用会提前执行 `conv_s0/conv_s1` 的 `forward_image()`。

训练时重算投影层、两个卷积与完整活动解码路径。未做冻结后缓存的随机图像增强；图像、提示、裁剪或分辨率改变，都必须重建缓存。后续带掩码反馈的第二个 `[SEG]` 不能沿用此缓存策略。

缓存绑定：权重文件实际 SHA256、官方代码、提示词、助手前缀、图像处理、软件版本、整个数据清单、每张 RGB 和缓存文件哈希。旧缓存不匹配时直接报错。缓存阶段不把 GT 输入模型；标签只用于训练损失、验证和测试计分。

默认 InternVL 最大图块数为 1，SAM2 输入为官方 1024×1024 直接缩放；这是控制 8B 冻结推理显存的选择，不是调低 SAM2 分辨率。可在预检时选择 `--max-patches 4`，但必须对 R1/M1/M2 全部保持一致，并用新的缓存目录。自动调度默认 1；若要改为 4，请同步改调度参数，不能混用。

## 损失与超参数

令有效像素权重为真实像素面积 `a_i` 乘标签有效掩码 `v_i`，归一化分母为有效总面积。每个候选：

- `BCE`：按有效面积加权的二元交叉熵。
- `Dice`：有效区域上的软 Dice；无水 GT 时置该项为 0，保留 BCE，避免空目标 Dice 不稳定。
- `L_quality`：三个候选的预测 IoU 与阈值化掩码真实有效区域面积 IoU 的 MSE，目标停止梯度。
- `L_area = |预测软水体面积 / 有效总面积 − GT 水体面积 / 有效总面积|`。

`M1 = mean(BCE + Dice) + 0.1 L_quality`。

`M2 = M1 + 0.1 mean(L_area)`。

新增 IoU 辅助项是为了正确训练官方的多候选选择分支；它在 M1/M2 中一致。面积项使用 0–1 的面积比例，不是直接使用平方米，避免尺度压倒分割损失。损失函数不保证必然提升，须以验证、测试结果判断。

单张微批次、累计 8 次再更新；AdamW，解码器学习率 `1e-4`，投影层 `2e-5`，weight decay `0.01`，梯度裁剪 `1.0`，BF16 自动混合精度、FP32 可训练权重。最多 1000 次**优化器更新**，每 100 次完整验证一次，连续 5 次未提升停止，单次最多 3 小时。固定学习率以减少调参维度。

验证集 micro IoU 最大者为 best；完全相同才用面积 MAE 决胜。第 0 步先评估 R1；训练全部变差时 `best.pt` 保留第 0 步并在 `status.json` 标记，不能宣称模型提升。`latest.pt` 只用于恢复权重或排查，不保证通过最新验证。当前入口不实现优化器中途续训；重复实验使用新目录、从统一基线开始。

## 数据与评价口径

只使用 Sen1Floods11 v1.1 手工标注官方清单：train 252、val 89、test 90、Bolivia 15，总共 446 张，输入为 13 波段 S2，标签为 LabelHand。本工具包不下载 S1，不把雷达输入混入 RGB 模型。

`data.py` 使用一基波段 B4/B3/B2，反射率缩放除 10000，固定上限 0.3 后映射到 RGB8。这个显式新处理方案须与队友原流程区别记录；不根据测试表现选择拉伸上限。保留所有有有效像素的样本，包括无水、低水比例、低有效覆盖样本。全无效标签样本记录在 `excluded` 中，其他缺文件直接报错，不能悄悄只跑“效果好”的子集。

标签 `−1` / `255` 无效，0 非水，1 水；每次检查空间尺寸、CRS 和仿射变换，配准不符直接停止。训练与评估都屏蔽无效标签，不把它当背景。RGB 生成不使用标签有效区，也不使用 GT 道路范围。

EPSG:4326 的北向上数据按 WGS84 椭球逐行计算像元面积；投影坐标系按坐标单位转换为平方米。旋转的地理坐标栅格等不支持情况明确报错。不能将经纬度平方直接当平方米。

输出指标：像素 micro IoU、micro Dice、非空并集的 macro IoU、有水 GT 的 macro IoU、无水样本误报比例、每图有效区域水体比例 MAE（百分点）、面积 MAE（平方米）、有效覆盖率、逐图混淆统计。空 GT 且空预测的 IoU 记为未定义，单独计数；不以大量空样本把平均 IoU 凑高。

阈值固定 0.5，掩码先按官方路径双线性恢复到 1024，再恢复原始标签网格；不 resize GT。GeoTIFF 保留原始 CRS/变换，输出 0/1，255 为无效。给 TerraScope 平台导入 GeoTIFF 时保留 nodata。

官方手工标注是水体，不自动区分常年水与灾害新增积水。此实验只能支持“水体分割与空间统计核验”的结论。道路受淹识别、真实灾前灾后变化及植被类别不能直接继承此结论。后续道路实验需独立道路矢量，不用 GT 道路掩码定义输入。

## 如何报告结果

冻结配置、用验证集选好模型之后，统一评估 test 与独立 Bolivia。报告 R1、M1、M2、第二种子，包含失败样本，不仅展示成功配图。不要把验证集最佳值写成测试值；不要用旧分享包中已查阅的测试样本继续挑阈值、提示词或损失权重。

`compare.py` 配对 bootstrap 给出 micro IoU 差、面积 MAE 差及区间。默认按瓦片抽样，空间相邻瓦片并不独立；可额外用 `--unit country` 做粗粒度敏感性分析，但国家不是严格事件 ID，事件数少时区间也不稳定。Bolivia 只有一个国家，不可做 country bootstrap。两种子结果只能作为稳定性检查，不代表充分统计证明。

执行顺序：数据和面积口径正确 → R1 → M1 → M2 → 第二种子 → 最终测试与导出。调度器会为最终评价保留时间，必要时跳过 M2/第二种子并记录原因；也可主动使用 `--skip-m2 --skip-second-seed`。不要为了完成所有消融放宽数据隔离或超预算。若未提升，保留 R1 并报告结果；不承诺提前达到某个百分点提升。
