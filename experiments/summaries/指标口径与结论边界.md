# 实验口径与结果解释

## 数据

FloodNet-Supervised v1.0，使用 RGB 航拍影像。受淹道路标签为类别 3；标签 255 为无效像元。训练 300 幅（162 幅含目标），验证 80 幅（30 幅含目标），完整测试 448 幅（49 幅含目标），额外留出 370 幅（23 幅含目标）。818 幅评估 = 448 + 370，不含 80 幅验证集。

额外 370 幅来自同一洪灾事件，未用于这轮训练和配置选择；这支持同事件留出检查，不是跨灾害或跨地区泛化证明。原 448 幅此前用于过项目探索，应保留这一研究背景，不能包装成从未看过的全新盲测。

## 最终配置

固定任务提示、RGB 输入；冻结主干，仅训练 `text_hidden_fcs` 和 `sam_mask_decoder`。最终采用 `long_bce_lovasz_seed20261017` 检查点及四视图平均，依据 80 幅验证集选择。夜间 BCE+Dice 和 BCE+Lovász 各三个种子、每组 4800 微步（1200 次优化器更新）。语言 LoRA、额外模块和参数平均都是对照/探索，不在最终组合中。

原始 protocol JSON 是逐阶段继承的配置快照，可能保留未启用的 LoRA 超参数字段。不要仅看到 `lora_rank` 就断言最终方案用了 LoRA；以训练脚本中的开关、实际梯度模块和结果报告为准。

## 评价定义

- 像素全局 IoU = 全部有效像元的 TP / (TP+FP+FN)，不是逐图 IoU 的简单平均。
- 覆盖率 = 受淹道路像元 / 该影像有效像元。不是“道路总长度中受淹比例”，也不是“所有道路像元中受淹比例”。
- 覆盖率 MAE 单位为百分点，误差在每幅图计算后平均。
- 场景判断使用预测受淹道路覆盖率至少 1% 的固定规则。场景命中、误报和像素 IoU 是不同层面的指标。
- 没有可靠地理分辨率时，不能凭 PNG 推算平方千米、道路公里数或受灾人口。

## 讲结果时应保留的区别

原模型 → 任务适配，定位与误报显著改善；单视图 → 四视图，主要优势是降低误报，额外 370 幅上的定位也改善。448 幅上四视图 IoU 为 58.28%，单视图为 58.63%，不要声称所有指标均提高。

与原模型比较，最终测试 IoU 提高约 49.62 个百分点。误报 169→2 是场景数的变化；若说“减少 98.8%”，必须说明是这一测试集中误报数量的相对降幅，不能说整套系统准确率 98.8%。

BCE+Lovász 选出的最佳种子高，但三种子均值并不超过 BCE+Dice，不能说 Lovász 普遍优于 Dice。自动空间提示试验没有证明模块本身有用：开关提示对照没有优势，最终未采用。
