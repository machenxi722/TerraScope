# 本轮实现与验收记录

验收日期：2026 年 10 月 16 至 19 日。环境：当前 macOS 本机，Python 3.12.14，Node.js 25.9.0，Chrome 无头测试；本地 SQLite + 独立 CPU Worker。目标部署版本为 Python 3.12、Node.js 22+、PostgreSQL 16、Redis 7、Celery 5.6。Docker 和 CUDA 在本机不可用。

## 实测结果

- pytest：**10 项通过**。覆盖真实像素、无 GT、未知影像拒绝回放、外部掩膜、重复提交、并发执行去重、取消重试、过期租约恢复、文件损坏、项目权限、CSRF、归档、上传限制、复核冲突、报告快照与 ZIP 哈希；GPU HTTP 协议使用测试替身验证。
- Vitest：**5 项通过**，覆盖四角/像素中心变换、边界像素、圈选约束、null 指标与来源状态区别。
- Playwright：**1 条完整业务链通过**，约 10 秒。实际执行登录→建项→导入 7301→分析→视图切换→圈选→保存复核→刷新→切页再返回→生成报告→下载 ZIP→评估与系统状态检查。浏览器拦截所有非 localhost/127.0.0.1 请求；流程未请求外部资源，无页面脚本异常。
- TypeScript 检查与 Vite 生产构建通过，预构建产物位于 `frontend/dist`。
- Alembic upgrade/check 通过，无待生成迁移；PostgreSQL DDL 离线编译成功，存于 `schema-postgresql.sql`。
- Compose YAML 静态结构检查通过：web/api/worker/postgres/redis 五个服务，只有 web 绑定宿主机回环端口。

7301 四视图实算：预测像素 **152,585**，有效像素 **701,440**，覆盖率 **21.7531078923%**；TP **140,651**，FP **11,934**，FN **39,168**。448 幅测试集全局 IoU **58.27679429197%**；370 幅留出集 **55.68506151576%**。

本地轻量性能采样：40 次串行、已认证 GET /projects，经 Vite 代理访问开发 API，p50 **3.73 ms**，p95 **5.15 ms**。一次已完成单景报告从快照创建到 ZIP 资产记录约 **1.121 秒**。这些仅是本机小数据集采样，不是并发压测，也不代表 PostgreSQL 生产环境、目标机器切图或 GPU 性能。原始记录在 `evidence/local-query-sample.json`。

## 前后端连接复查（2026-10-18）
