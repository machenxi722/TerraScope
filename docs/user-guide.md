# 使用手册

## 账号和项目

使用 `.env` 中的初始化账号登录。系统管理员可在系统设置创建普通账号，再为当前项目分配分析员、复核员或只读角色。创建项目的人获得该项目管理员角色。顶部项目选择器控制影像、任务、评估与报告列表的项目范围。项目管理员可在成员表编辑角色或移除访问权限；项目至少保留一位管理员。审计记录支持翻页。会话过期后重新登录会返回原页面。

项目可编辑说明或归档；归档后不能继续写入，可以恢复。初始化示范项目是幂等操作，不会清空原有复核与报告。需要一套全新的示范数据时，先归档旧示范项目再初始化，旧资料仍可访问。

## 影像与分析

支持单帧 JPG/PNG，文件不超过 20 MB，总像素不超过 2500 万。格式扩展名、MIME 和实际解码必须一致。系统计算原始文件哈希，同项目相同字节复用已有影像。采集时间未知时保持为空，不将导入时间当作采集时间。上传后直接进入工作台；影像列表同时搜索文件名和样本 ID。

案例库内 10 幅是真实 RGB 和标签；6597 是训练示例，没有最终预测。其他 9 幅有单视图和四视图结果。选择“历史结果”时，只有严格匹配的策略可提交；新图无匹配时按钮不可用。

“外部导入”接受与原始网格一致的二值 PNG，值域为 0/1 或 0/255。浏览器帮助计算掩膜 SHA256，用户仍须填写模型版本、预处理版本、策略和来源说明。服务端复核哈希、尺寸和编码，结果标记为外部来源，模型说明不被当作已验证版本。

GPU 未连接时不能提交“本次推理”。模型服务通过 HTTPS 或本机 SSH 加密隧道连接，并校验令牌与模型版本。AutoDL 实例开机后，运行 `scripts/start-autodl.command` 即可连接。推理超时不会自动切换到历史结果。工作台显示当前任务状态、错误和阶段日志，并可取消或重试。外部导入和分析完成后自动选中新结果；结果链接保留所选版本。

## 判读和复核

工作台左侧分为“可视化”和“分析设置”。“可视化”中按结果生成日期、数据来源筛选版本；“全部日期”只清除日期，“重置筛选”同时清除日期和来源。筛选不会自动切换正在判读的结果，也不会清除未提交的复核草稿。采集时间未知时明确显示“未提供”。

地图右侧工具栏依次打开统计分析、区域选择、人工复核、来源详情，下面提供适配全图、缩放和报告导出。再次点击选中工具或关闭按钮可收起详情面板。左侧参数面板也可收起，以扩大影像区域。手机屏幕中参数面板排列在地图下方，详情面板为可关闭的浮层。

叠加模式调节透明度；卷帘模式调节遮罩位置；同步对比共用中心和缩放，右侧可选择另一预测版本或原始影像。F 适配全图。点击像素查看 RGB、预测类别、参考类别与有效性。TP/FP/FN 固定使用绿、红、黄图例，只有存在标签才提供差异图。

复核员在“区域选择”或“人工复核”面板圈选多边形、填写依据并提交确认、退回或需补充调查。双击或点击首顶点闭合区域，Esc 取消正在绘制的区域。区域绑定当前预测；查看历史复核可重新载入当时的圈选。保存不修改原始掩膜。圈选是调查注记，统计分析继续使用整幅影像，不把像素数量误写为区域面积。

复核带 base_revision。如果他人先保存，系统返回 409；先比较历史记录，再明确基于最新版本继续。不要仅通过反复提交覆盖别人的修改。

## 报告与解释边界

在工作台生成报告后到报告中心下载。PDF 提供影像、模型来源、指标、复核和边界说明；ZIP 还包含原始输入、显示图、掩膜、CSV、元数据、可选差异图与 SHA256SUMS。旧报告固定保留当时版本。报告中心支持单独下载叠加图、JSON，并返回对应预测结果。

覆盖率是影像有效区域内的受淹道路预测比例，不是所有道路受淹占比。没有标签就不提供准确率、IoU 或误差图。没有地理配准就不计算平方米。低于 1% 的筛查阈值不等于道路安全可通行。调查结论需要结合现场核查。

实验评估支持按分区、策略、样本 ID 检索，测试集 448 幅与留出集 370 幅分别展示；验证集 80 幅用于模型机制核对。大多数记录没有原图，不提供虚构案例图。四视图在测试集主要降低误报，不是所有指标都有提升。

实验逐景表可直接查看当前策略的历史结果；案例库中已有原图的记录可“导入并分析”。CSV 导出遵循当前分区、策略和样本筛选，包含全部匹配记录，不受页数限制。
