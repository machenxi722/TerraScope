# TerraScope UI 1.2

## 布局与配色

主视图按本轮提供的 Copernicus Browser 截图实现。桌面采用固定比例的双栏：左侧 40%，右侧 60%。品牌、项目选择、模块导航与工作台页签全部位于左侧，影像从页面顶部延伸到底部状态栏。

参考：[Copernicus Browser](https://browser.dataspace.copernicus.eu/)、[Esri Calcite 字体与信息层级](https://developers.arcgis.com/calcite-design-system/foundations/typography/)。

## 工作台

- **可视化**：当前影像缩略图、并列日期/来源筛选、结果版本列表、四种图层缩略图、不透明度、叠加/卷帘/同步对比、结果摘要。
- **分析设置**：分析来源、策略、模型、提交任务、外部结果导入与服务状态。分析完成后自动切换到最新结果。
- **统计**：影像内预测覆盖率、有效像素、受淹道路像素、参考标签指标与复核状态。
- **复核**：区域圈选、撤销、清空、结论与依据、复核历史。
- **地图工具**：右侧竖排统计、区域、复核、来源与报告；缩放、适配全图和填充视图位于右下方。
- **底部状态**：像素查询、圈选数量、结果时间与版本前后切换。

统计、复核和来源详情在左栏内切换，地图宽度不变。收起左栏后地图扩展至全宽，点击地图工具会恢复左栏。各控件保留独立状态；日期/来源筛选不清除当前结果或复核草稿。

默认填充视图占满画布，允许影像边缘超出视口。适配全图或快捷键 F 显示完整影像。图层缩略图由当前影像和实际结果资产生成；像素投影、预测颜色与计算结果沿用原有实现。

小于等于 720 px 时采用纵向布局，地图在前，参数在后。桌面与平板保持 40%/60% 分栏。

## 全站

项目、影像、任务、实验、报告与设置共用同一配色和字体规范。缩小卡片间距、表单标签间距及表格行高，去除重复说明与装饰性英文。技术信息集中在来源详情和系统设置。

前后端 API、权限、队列、复核版本与报告快照契约保持兼容。

## 验证

2026-10-18：前端类型检查和生产构建、7 项前端单元测试、10 项后端测试通过。浏览器回归覆盖：

- 7301 真实案例分析，覆盖率 21.75%，受淹道路像素 152,585，有效像素 701,440。
- 原始影像、预测、卷帘、同步对比、区域圈选、保存复核及刷新恢复。
- 多结果版本的前后切换、首尾按钮禁用、日期与来源筛选后保留当前结果。
- 左右栏比例、地图顶端位置、左侧工具切换不改变地图宽度、收起和恢复左栏。
- 1366 × 900、1024 × 768、390 × 844 下无横向页面溢出。
- 报告 ZIP 下载、实验评估和系统状态。

界面截图保存在 `docs/evidence/`，包括 `workbench.png`、`ui-comparison.png`、`ui-review.png`、`ui-1024.png` 和 `ui-390.png`。
