```sh
python3 scripts/verify_repository.py
```

发布调整包括总 README、实验/权重/数据说明与最终配置、无数据集启动、清晰的数据缺失提示、按数据存在与否运行真实案例测试、示例 SSH 配置去除现有地址。历史实验代码仍保留原路径与限时。

权重、PPT、PDF、字体与视频为 Git LFS 文件，须 `git lfs pull` 后使用。完整上游底座及其他未交接 checkpoint 不在本地，提供已有来源与清单说明。
