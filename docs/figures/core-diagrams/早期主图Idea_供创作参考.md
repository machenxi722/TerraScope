# TerraScope 四张主图 Idea：详细开放版

这份说明用于向图像生成模型解释项目和画图意图。机制与信息关系需要准确，构图和表现方式可以自由探索。下面的文字是供理解的设计素材，不需要全部变成图中文字。

## 如何使用

每次生成一张图时，提供“共同背景”和对应主图的说明，并附上自己喜欢的论文图。可以让图像生成模型提出不同构图，再选出最有潜力的一版细化。参考图的价值包括空间结构、信息组织和阅读路径，不只包括配色或装饰。

当我明确选中一张参考图的结构时，请保留它的主要空间关系，例如中央大模型、下方展开的分割支路、右侧输出和回注环路。在此基础上改进局部细节、视觉层次和美感。没有指定结构时，可以自由尝试不同布局。

## 共同背景

这是一个面向洪灾道路调查的课堂研究项目。灾后需要及时查清哪些道路受淹，以及影像中受淹道路所占的范围。无人机 RGB 航拍能提供局部区域的细节，后续仍需要判读、定位和统计。我们的项目利用 TerraScope，把自然语言指定的目标与像素级分割联系起来，再适配到“受淹道路”这一任务。

TerraScope 是原有的遥感多模态模型，基于 InternVL3，并已包含 SAM2 分割组件。本组的主要工作是任务化微调、四视图融合推理和道路定位及覆盖率评价。SAM2 不是我们新加的模块。

四张图各有一个明确的问题：

| 主图 | 听众应该看懂的问题 | 画面的核心内容 |
| --- | --- | --- |
| 原模型原理 | 语言问题如何与影像中的目标区域联系起来？ | 多模态理解、SEG 分割提示、掩膜、REGION 证据反馈 |
| 本组流程总览 | 我们做了哪些工作，这些工作如何构成完整流程？ | 离线任务适配、权重选择、四视图推理、调查输出 |
| 轻量任务微调 | 到底训练了模型的哪些部分？ | 冻结表征、可训练投影与掩膜头、像素监督和反向更新 |
| 四视图融合 | 为什么要换方向预测，怎样把结果正确合在一起？ | 同图四视图、共享权重、逆变换恢复坐标、分数融合 |

整体倾向于正式科研论文的方法图：信息丰富、关系清楚、层次分明。中文宋体风格，英文及数字 Times New Roman 风格。配色可以在蓝灰、鼠尾草绿、浅紫、暖杏色等清新低饱和方向探索，兼容现有 PPT 的深绿色标题。颜色最好承担语义，例如帮助区分语言、视觉、分割和区域反馈。

视觉 token、特征张量、网络层、掩膜、影像局部放大都可以成为表达机制的元素。细节应服务于理解，可以有精致的层叠、轮廓、轻微立体感和局部高亮。无需把每一步都装进相同的方框。

真实影像、掩膜、覆盖率和实验指标最后会替换为本地文件。生成阶段可以用占位示意探索构图，但示意的预测、数字和差异图不作为实验结果。

## 主图一：TerraScope 的语言引导分割与区域证据反馈

### 这张图的故事

输入一幅遥感影像和一句问题，例如“这张图中水面的覆盖率是多少”。模型理解问题所关心的地物，在影像中定位目标，获得对应区域的视觉信息，并据此继续生成回答。画面需要让听众理解：语言、分割和区域证据之间有明确的信息联系。

这张图承担模型原理介绍，完整讲原模型的问答与证据反馈机制。它与后面“本组具体训练什么”是两个层次。

### 机制如何发生

影像有两个相关的处理分支。第一条分支通过视觉编码器和投影，将影像转化为语言模型能够使用的视觉 token。自然语言问题也变成文本 token。两类信息共同进入 InternVL3，支持模型理解“要关注什么”。动态切片、图像 patch 和 token 序列可以帮助表现视觉信息如何进入语言空间。

第二条分支通过 SAM2 图像编码器提取空间特征。这个分支保留供像素定位使用的图像信息，可以用多个尺度的特征层表现。

语言模型生成 `[SEG]` 控制标记时，对应的隐藏状态经过 SEG 投影 MLP，转为分割提示。SAM2 掩膜解码器接收这个提示以及图像特征，输出目标的像素掩膜。这里应表现出两类信息的汇合：语言告诉模型要找什么，图像特征帮助模型定位在哪里。

掩膜还用于在视觉 token 中选取对应区域的特征。这些区域特征以 `<REGION>` token 的形式回注语言模型，支持后续回答。反馈的是区域视觉信息，掩膜承担空间定位和选择的作用。

最终可以同时展示一句自然语言回答、一张二值掩膜，以及掩膜叠加到原图上的效果。三种表达分别说明回答内容、目标形状和真实空间位置。

### 值得展开的视觉细节

可以把多模态语言模型作为视觉中心，展示少量 Transformer 层或输入序列。SEG 标记及其隐藏状态、提示投影、SAM2 的多尺度特征、区域 token 的回注，是有意义的内部细节。回答示例与对应影像能帮助非 AI 专业听众理解这一机制。

若参考所附的中央大模型式构图，可以让影像和问题位于输入侧，SAM2 分割支路在下方展开，区域证据沿反馈回路返回中央，结果在另一侧集中呈现。允许重新调整比例、层级和局部组织，让主路径清楚、反馈路径容易跟随。

### 技术含义要保持一致

模型名称使用 InternVL3。SAM2 包含图像编码与掩膜解码两个不同部分。区域反馈按本地代码表现为“依据掩膜选取视觉 token”，区域 token 可以有多个，不必画成一个固定的均值池化向量。

SEG 是与分割提示相关的控制标记；REGION 携带对应区域的视觉特征。两者最好在语义上容易区分。

本组后续的道路专用推理采用固定分割提示及 SEG 输出前缀，没有执行完整的自由问答反馈循环。因此，完整 REGION 回路属于这张原模型原理图；后面的本组流程图围绕实际道路分割流程展开。

如果在原理图上同时标出本组的微调位置，雪花和火焰的图例需要说明它们代表“本组微调时的参数状态”。视觉、语言及 SAM2 图像编码器冻结，SEG 投影和 SAM2 掩膜解码器参与训练。

## 主图二：本组的洪灾道路调查流程

### 这张图的故事

我们从现成的遥感模型出发，利用带标签的洪灾航拍影像完成任务适配，再把得到的模型用于道路解译。预测结果经过四视图融合，转化成可以查看位置、核算覆盖率和逐景核查的调查成果。

听众应该能沿着这张图回答：数据从哪里进入，模型能力在哪里改变，推理阶段增加了什么，最终得到了哪些可以使用的结果。

### 流程中的关系

离线阶段接收配对的 RGB 影像和受淹道路标签。影像作为模型输入，标签用于训练监督。微调集中在 SEG 投影和 SAM2 掩膜头。验证集用于选择任务权重和部署配置，最终得到一组可以保存和复用的权重。

模型使用阶段接收待处理的 RGB 影像和道路分割任务。四种视图使用同一组模型权重进行预测，结果经过坐标恢复、分数融合和阈值化，形成最终道路掩膜。

掩膜叠加到原图，提供目标的具体位置；统计掩膜像素所占比例，得到覆盖率；结合逐景输出，形成待核查的影像或区域记录。有真实标签的实验数据还可以用于评价空间重合程度、覆盖率误差和场景误报。

### 本组贡献如何成为画面重点

任务适配解决“通用模型如何聚焦受淹道路”；四视图融合汇总同一位置的多次判断；空间统计将分割结果转为调查输出。这三个环节可以在整条流程中被辨认出来，彼此又是连续的。

“离线学习”和“后续使用”存在阶段区别。可以通过上下层、主干与支路、权重交接、展开的局部细节等方式表达，不规定一定采用哪一种。数据集可以用真实影像与标签的配对来表现，模型可以有内部结构，输出可以用地图叠加和简洁的统计记录来表现。

### 可选的信息素材

实际规模为 300 幅训练影像、80 幅验证影像、448 幅完整测试影像，以及额外 370 幅评价影像。总览图可以根据清晰度选择是否放这些数字。详细分组与结果可以留给实验页。

这里的道路覆盖率表示“受淹道路像素占有效影像像素的比例”。目前这条应用线没有可靠的地面尺度，不把像素比例直接标成道路长度或平方米，也不把道路掩膜说成整场洪水的全部淹没范围。

真实标签参与监督和评价，使用阶段的预测输入不包含标签。实际主流程没有必须由人逐幅手工圈绘的步骤；人工查看结果可以作为使用场景，但不应画成我们已经完成的大规模人工验证实验。

## 主图三：轻量任务微调的训练范围与监督机制

### 这张图的故事

预训练模型已经具有视觉和语言表征能力。我们利用受淹道路标签，调整少量直接影响分割提示和像素预测的参数，使已有模型适应这个具体任务。

画面应该让人一眼看到哪些部分保持冻结、哪些部分发生更新，以及真实标签如何影响预测。雪花和火焰是表达训练范围的语义符号，应有实际对应对象。

### 保持冻结的部分

视觉编码器和视觉到语言的投影提供视觉 token，InternVL3 结合视觉输入与任务文字产生与 SEG 对应的隐藏状态。SAM2 图像编码器提供空间特征。这些预训练表征部分在最终选用的任务适配方案中保持冻结。

它们可以组成一个较完整的基础模型部分，也可以分布在两条输入分支中。冻结意味着这些参数不被优化器更新，不代表这个部分不参与前向计算。

### 参与训练的两个接口

第一个接口是 SEG 提示投影 MLP。它将语言隐藏状态映射为 SAM2 能接收的分割提示，结构为 Linear、ReLU、Linear。若需要展示张量维度，实际是 3584 → 3584 → 256。维度信息是可选细节，核心是让听众理解语言表示如何进入分割空间。

第二个接口是 SAM2 掩膜解码器。它结合分割提示与图像特征，输出道路像素预测。可以适当展开提示融合和掩膜生成，让“更新分割能力”在图中有明确对象。

这两个部分共约 17.98 M 可训练参数。火焰应标在这两个模块，冻结部分可以使用雪花。可以通过颜色、线条或模块层次强化这种区别，不要求仅靠图标表达。

### 监督如何形成更新

模型输出的预测掩膜与真实受淹道路标签计算像素损失。本组比较 BCE + Dice 和 BCE + Lovasz 两类训练目标，损失反向更新投影层和掩膜解码器。

在画面中，真实标签应该进入损失比较，而不是成为语言模型预测时能够看到的输入。前向预测、标签监督和反向更新的方向需要易于辨认。可以将预测与标签并列，再由损失连接回可训练模块；也可以采用其他更自然的训练回路构图。

训练中的同步翻转以及亮度、对比度增强可以作为细节加入。几何增强时影像和标签同步变化，颜色变化作用于影像。不同损失和随机种子属于训练配置探索，不需要在这张机制图中堆满实验结果。

### 视觉创作空间

可以表现“完整底座中的局部适配位置”，也可以将关键接口放大，形成整体与局部的关系。网络层、语言 token、空间特征和真实道路掩膜能形成不同尺度的视觉元素。重点是让训练路径可追踪，同时保留模型的结构感。

LoRA、残差细节模块和道路辅助任务是探索过的对照配置，不属于最终选择的完整主流程。若此图讲最终方法，不把所有试验模块一起堆进去。

## 主图四：四视图推理中的坐标恢复与分数融合

### 这张图的故事

同一场景换一个方向进入模型，局部预测可能发生变化。我们让同一模型从四种方向处理同一影像，再将这些判断恢复到同一个空间坐标下汇总，形成最终预测。

最重要的视觉关系是：同一条道路在不同输入中改变了方向，逆变换后重新回到同一个位置。听众应能直接看出为什么需要先对齐，再融合。

### 四路预测如何形成

一幅 RGB 影像构成原图、水平翻转、垂直翻转和双向翻转四种视图。四路共享同一组训练好的权重，各得到一张像素预测分数图。

这些输出首先处于各自输入的坐标方向。水平翻转的输出需要水平翻回，垂直翻转的输出需要垂直翻回，双向翻转的输出需要在两个方向都恢复。原图预测保持原方向。

经过逆变换，四路预测的每个像素对应同一个地面位置。随后逐像素平均四路 logits，恢复到原始影像尺寸，再以零为 logits 阈值生成二值掩膜。最后可以展示与 RGB 叠加的道路定位结果。

### 为什么值得把它画出来

四路输出可以在整体形状上相近，又在道路边缘、窄小路段或误报区域上存在差异。图中可以选一处局部区域，表现这些差异怎样在坐标恢复后被比较和汇总。既可以用完整影像，也可以借助局部放大、同位置标记、分数热图或层叠对齐来讲清楚。

四种视图来自同一张影像，不是四个地点、四个时刻或四种传感器。四路使用同一组权重，不是分别训练四个模型。它发生在推理阶段，不是一次新的训练过程。

融合对象是阈值化前的 logits 分数。二值掩膜适合清楚展示形状和方向，但若作为中间示意，需要保持“先分数融合、后阈值化”的实际顺序。

### 可以怎样自由发挥

这张图可以围绕方向变换组织，也可以围绕一个共同的空间位置组织。输入视图、原方向预测、恢复坐标后的预测和最终融合结果之间，需要有清晰的阅读顺序。具体采用横向展开、围绕中心汇聚、分层展开，还是带局部放大的构图，都可以探索。

如果使用局部例子，让它承担一个明确解释：例如某一方向下的零散误报，经过其他方向的判断汇总后响应减弱。示意仅用于解释可能的机制，实际效果由后续真实结果页说明。

本组结果支持四视图减少部分场景误报，但它并非对所有影像、所有指标都更好。方法图表达其计算机制和设计动机，不需要虚构“完美分割”或在图中生成未经核对的提升数字。

## 交给图像生成模型时的一段总说明

请充分理解上述机制，再设计一张正式、精致、信息丰富的方法图。优先保证空间组织和阅读路径，让各模块的作用、输入与输出能通过画面本身被理解。结构关系明确的前提下，你可以自由安排构图比例、局部展开、视觉隐喻、材质和配色细节。所列细节是可选择的表达素材，不要求全部塞进画面。

如已提供并选定参考图，请学习其结构和信息组织，再适配本项目内容。保留有意义的 token、特征层、分割掩膜、训练状态符号与反馈关系，避免在美化时把模型压缩成几个笼统方框。真实实验图像与数字会在后续制作 PPT 时替换和核对。
