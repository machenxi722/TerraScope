TerraScope 截图索引与 PPT 配文
主案例 7598；GPS 补充 6480；录屏另用 7611。

01_登录入口.jpg
操作：打开本地地址并使用管理员账号登录。
配文：统一身份入口，将项目资料、模型任务和调查成果集中管理。

02_创建调查项目.jpg
操作：新建“小组展示 · 7598 居民区道路调查”，进入该项目。
配文：以项目组织影像、预测、人工复核和成果文件，形成完整调查记录。

03_完整实验影像库.jpg
操作：影像资料 → 从案例库导入；浏览缩略图、分区与分页。
配文：接入 1,198 幅实验 RGB 及对应标签，支持按样本和实验分区快速选片。

04_GPS样本分布.jpg
操作：案例库切换“拍摄点”，点击聚合点展开。
配文：895 幅影像带有原始 GPS 拍摄点，可在地图上浏览空间分布。

05_检索并导入7598.jpg
操作：搜索 7598 → 导入 → 关闭窗口。
配文：从完整实验库选取留出集影像，直接进入项目分析流程。

06_RGB解译工作台.jpg
操作：7598 卡片 → 打开工作台；查看原始影像并填充视图。
配文：左侧集中参数与统计，右侧大幅展示影像，兼顾信息密度和判读空间。

07_A800推理配置.jpg
操作：分析设置 → 本次推理 → 四视图增强 tta4 → 提交分析。
配文：调用 A800 上的模型处理当前 RGB，生成与输入网格一致的分割结果。

08_推理任务日志.jpg
操作：分析任务 → 对应 tta4 任务 → 阶段日志。
配文：从输入校验、GPU 推理到后处理逐阶段记录，结果生成过程可追踪。

09_真实推理结果叠加.jpg
操作：查看结果 → 预测图层 → 叠加；调整透明度。
配文：受淹道路以橙色叠加在 RGB 上，主干道路与交叉口的受淹分布直观可见。

10_RGB与预测卷帘对照.jpg
操作：可视化 → 卷帘；拖动中线检查道路边界。
配文：同一位置连续对照原图与预测，快速辨认树冠遮挡和道路边缘。

11_双视图同步对比.jpg
操作：切换“同步对比”，缩放与平移任一视图。
配文：两侧保持同一观察范围，支持细节核对和多结果对照。

12_误差分布与精度评估.jpg
操作：选择“误差分布”，打开“统计”。
配文：7598 四视图结果 IoU 为 85.05%，召回率 94.47%；误差图定位漏分和误分。

13_参考标签对照.jpg
操作：选择“参考标签”，与预测和原图交替查看。
配文：将参考标签接入判读工作台，用可视化证据核对自动识别结果。

14_圈选区域与复核依据.jpg
操作：区域选择 → 圈选道路交叉口 → 复核 → 确认结果 → 保存复核。
配文：人工圈选重点核查区域并记录判断依据，复核意见独立保存为版本。

15_报告与成果下载.jpg
操作：生成报告 → 报告中心 → ZIP 证据包或 PDF、CSV。
配文：报告锁定复核 v1，同步输出图件、统计、元数据和文件校验清单。

16_GPS定位与拍摄信息.jpg
操作：同项目导入 6480；打开工作台 → GPS 定位。
配文：相机拍摄点与原始采集时间共同呈现，补充影像的空间来源信息。

17_含GPS的成果导出.jpg
操作：6480 选择历史结果 tta4，生成报告，下载 GPS 或 ZIP。
配文：有 GPS 的影像额外输出 GeoJSON 点文件，可继续用于 GIS 展示。

18_留出集与单景评估.jpg
操作：实验评估 → 留出集 → 切换策略、检索样本、查看明细。
配文：整体评估和逐景结果在同一页面衔接，支持从实验指标追溯到具体影像。

19_系统能力与模型连接.jpg
操作：系统设置 → 数据能力和模型状态。
配文：资料规模、模型版本和运行设备集中可查，区分历史结果与当前推理来源。

20_单视图与四视图版本对照.jpg
操作：7598 再运行单视图；选 tta4，进入同步对比并指定 single_view。
配文：同一 RGB 对照两种策略；本景 IoU 从 84.58% 提升到 85.05%。

21_像素查询与调查成果.jpg
操作：返回 tta4 叠加，打开统计并点击道路像素。
配文：逐像素查询 RGB、预测和参考类别，同时查看统计与已保存的复核区域。
